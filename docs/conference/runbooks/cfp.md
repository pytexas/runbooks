# Call for Proposals Runbook

Speaker Committee owns this. Platform: [Pretalx](https://pretalx.com).

See `speaker-committee-runbook.md` for full speaker workflow.

## Timeline

- October 1: CFP opens
- December 1: early bird tickets open
- Early December: CFP closes
- December (holidays): review (min 2 full weeks)
- Early January: speaker notifications
- Mid-January: speaker list announced
- Mid-January: early bird closes

Start CFP prep 2 months before opening.

## Pre-Launch

### Pretalx Setup
- [ ] Create/update conference: `https://pretalx.com/pytexas-[YEAR]`
- [ ] Configure submission form: title, abstract (public), description (reviewer), bio, headshot, socials, contact, level (Beg/Int/Adv), notes; talks are a single 30-minute length (25-minute talk plus 5 minutes of Q&A and changeover)
- [ ] Include a travel-assistance question (will the speaker need help getting here?); answers feed opportunity grant planning, see `grants.md`
- [ ] Set deadline
- [ ] Configure reviewer accounts
- [ ] Update email templates
- [ ] Test submission end-to-end

### Marketing Coordination
- [ ] Announcement graphics + copy
- [ ] Social campaign schedule
- [ ] Newsletter announcement (1st of month)
- [ ] Site updates
- [ ] Discord post

### Past Speaker Outreach

Direct outreach to past speakers generates quality submissions; treat it as a core part of the campaign, not an extra.

- [ ] Confirm access to the per-year past-speaker Google Group (a new group each year; check with the outgoing speaker chair)
- [ ] Prepare CFP invitation email for past speakers

## Launch Day

- [ ] Open submissions in Pretalx
- [ ] Send past-speaker invitations
- [ ] Post: social (Buffer), newsletter, site, PyTexas Discord, Python community Slacks/Discords, LinkedIn/Mastodon/BlueSky/Twitter

## During CFP

### Reminders
- Mid-window push (~November 1), including the Texas meetup lists
- Final week countdown before close

### Support
- [ ] Respond to inquiries within 24-48 hours
- [ ] Optional office hours if submission volume low

## Review

### Phase 1: Individual Review (Weeks 1-2)

Reviewers in Pretalx:
- Read all submissions
- Score in Pretalx system
- Notes on fit, experience level, topic, concerns

Scoring criteria:
- Content quality (abstract clear? description shows depth?)
- Audience fit (level + community relevance)
- Clarity (can you tell what the talk covers?)
- Timing (can they fit our time limits?)

### Phase 2: Committee Discussion (Week 3)

Format: in-person or video.

Agenda:
1. Top-scored (auto-accepts)
2. Middle tier (discussion)
3. Bottom tier (likely rejects)
4. Final accepted list
5. Waitlist
6. Track + schedule integration

Record the selection rationale; it is institutional memory for next year's committee.

## Notifications

### Acceptance (Early January)

Email includes:
- Conference dates + venue
- Response deadline (1-2 weeks)
- Confirm acceptance
- Updated bio if needed
- High-res headshot
- Social handles
- A/V requirements
- Accessibility needs
- Speaker benefits (free ticket, Friday appreciation dinner)
- Speaker resources link

### Rejection

Send at notification time, alongside the acceptances: reject everything below the ordered waitlist promptly.
Only waitlisted speakers wait; keep the waitlist ordered (roughly 10 deep) with the top few flagged.

Email:
- Thanks for submitting
- Encourage conference attendance
- Invite resubmission next year
- Optional feedback if requested

### Waitlist

- Keep the waitlist ordered, with the top candidates flagged
- Don't reject waitlisted speakers initially; promote in order on declines
- Offer standby speakers free tickets
- Send waitlist rejections once all accepted speakers have confirmed

## Post-Notification

### Speaker Announcement (Mid-January)
- [ ] Update site with speaker lineup
- [ ] Speaker spotlight graphics for social (the "Guess Who" teaser-then-reveal series)
- [ ] Remind attendees early bird closes mid-January

### Speaker Info Collection

Send the speaker information form (Google Form) with the acceptance email, not later.
Chasing this data after the fact is painful; response rates crater once the acceptance moment passes.

- [ ] High-res headshot
- [ ] Social handles
- [ ] Pronouns
- [ ] Company affiliation (if listed)
- [ ] Short bio
- [ ] Final talk title + public abstract

### Cross-Committee
- Marketing: promo + social
- Venue: A/V requirements, accessibility
- Venue: Friday appreciation dinner headcount
- Community: Discord + virtual engagement

## Tutorials

Tutorials are recruited by direct invitation, not through the open CFP.
Start recruiting in person at PyCon, about 11 months out, and keep a ranked shortlist with backups.
Tutorial recruiting runs earlier than the talk CFP because tutorials need more prep.
