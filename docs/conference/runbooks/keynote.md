# Keynote Speaker Runbook

Owned by the Speaker Committee.

See `speaker-committee-runbook.md`.

## Timeline

- Month -8 (kickoff, mid-August): open the nomination form
- End of September: close nominations
- Early October: organizer election (ranked ballot)
- Late October: decide the ordered invite list
- November: outreach down the list
- By Month -5: keynotes confirmed
- January: public announcement with the speaker list
- Feb-Mar: coordinate talks, A/V, travel
- April: day-of

## Nominations

Tool: Google Form, opened at the kickoff meeting and closed end of September.
The form and its responses live in the year's Drive folder under Speakers.
Community nomination generates a more diverse candidate pool than organizer brainstorming alone; promote the form widely.

Form fields:
- Nominee name
- Contact info if known
- Why a great keynote
- Topic areas
- Links to prior talks/content
- Nominator name (optional)

Promote with Marketing:
- PyTexas social
- Discord
- Newsletter
- Organizer networks
- Python community Slacks

Run 4-6 weeks.

## Selection

### Organizer Election

Once nominations close, run a ranked-ballot election among the organizers (Google Form).
Each organizer scores every candidate from +2 to -2.
Compile the results into a rankings doc with vote scores, then decide the ordered invite list as a team (late October).

The invite order is the plan.
Rank the list at least five or six candidates deep; invitations often go several names down before someone accepts.

Criteria:
- Speaking experience (quality, stage presence)
- Topic relevance
- Diversity
- Community impact
- Availability
- Draw factor

### Discussion
- Review top-ranked
- Pros/cons
- Balance (topics, backgrounds, lengths)
- Backup options
- Ordered invite list

The standard format is two keynotes, one each day, right after opening remarks (~45 minutes each).
A sponsor-funded third slot is possible if a sponsor wants it.
Decide the count before outreach.

### Budget

Keynote benefits typically:
- Free conference pass
- Honorarium
- Travel reimbursement / stipend
- Hotel or lodging support (set the limit with Finance before outreach)
- Friday appreciation dinner invite
- Premium schedule slot

Coordinate with Finance on the keynote budget, honorarium policy, and travel/hotel limits before outreach, so the offer in the invitation is real.
Keynoters sometimes redirect or donate back their honorarium; redirected honoraria can seed the opportunity grant fund.
See `grants.md`.

## Outreach

### Initial Contact (November)
```
Subject: PyTexas [YEAR] keynote invitation

Hi [NAME],

PyTexas [YEAR] is [DATES] in [CITY]. Expecting [N] attendees.

Your work on [SPECIFIC AREA] would resonate with our audience.

Keynote includes:
- Free pass
- [Travel/hotel]
- [Honorarium]
- 45-minute keynote slot

Open to a brief call to discuss?

[NAME], Speaker Committee, PyTexas Foundation
```

### Follow-Up
- Initial: top 3-5 candidates
- 1 week: follow up if no response
- 2 weeks: move to next candidate
- Simultaneous outreach OK, but prepare for multiple yeses
- Some candidates take weeks to respond; build buffer into the outreach window

Be honest about timeline + backup plans. If they're #2 and #1 hasn't responded, say so.

### Declines
- Thank graciously
- Ask for referrals
- Invite them to attend or submit to CFP
- Keep on list for future years
- Move to next ranked candidate

## Confirming

On verbal/email agreement:
- [ ] Send formal confirmation
- [ ] Request bio (100-150 words)
- [ ] Request hi-res headshot
- [ ] Confirm conference dates work
- [ ] Tentative title + description
- [ ] A/V requirements
- [ ] Dietary restrictions
- [ ] Travel details for booking

Inform committees:
- Marketing: announcement coordination
- Finance: travel/hotel booking, honorarium
- Venue: A/V requirements, green room
- Community: Discord + virtual integration

## Public Announcement

Coordinate with Marketing for the mid-January speaker-list announcement, while early bird is still open.

Include:
- Keynote names + photos
- Brief bios
- Talk titles if available
- Why we're excited
- Conference dates reminder
- Register link

## Pre-Conference

### 2-3 Months Out
- [ ] Final titles + descriptions
- [ ] Final abstract for site + program
- [ ] Slide template (if offering)
- [ ] A/V needs (screen sharing, video, demos)
- [ ] Book travel + hotel with Finance
- [ ] Send logistics packet

### 1 Month Out
- [ ] Talk finalization reminder
- [ ] Offer tech check (especially remote/hybrid)
- [ ] Confirm arrival + Friday appreciation dinner attendance
- [ ] Friday appreciation dinner details
- [ ] Venue + parking/transit info

### Week Before
- [ ] Final arrival confirmation
- [ ] Speaker lounge/green room location
- [ ] Day-of organizer contacts
- [ ] Final conference schedule
- [ ] Last-minute A/V + accessibility needs

## Day-Of

### Check-In
- [ ] Meet keynote on arrival
- [ ] Show green room
- [ ] Walk through speaking room + A/V test
- [ ] Introduce to emcee
- [ ] Water + refreshments
- [ ] Organizer emergency contact

### During Talk
- [ ] Emcee has correct bio + intro
- [ ] A/V standing by
- [ ] Record (with permission)
- [ ] Time warnings
- [ ] Facilitate Q&A if part of format

### After
- [ ] Personal thanks
- [ ] Facilitate hallway conversations
- [ ] Food/coffee access
- [ ] Check needs for rest of day
- [ ] Photos with organizers/attendees (if willing)

## Post-Conference

### Week 1
- [ ] Thank-you email
- [ ] Photos from their talk
- [ ] Preliminary metrics
- [ ] Ask for feedback
- [ ] Confirm reimbursements in process

### Recording + Content (with Community)
- [ ] Edit and upload
- [ ] Share with speaker before publishing
- [ ] Social promo with tag
- [ ] Add to YouTube + archive

### Long-Term
- [ ] Add to past speakers Google Group
- [ ] Updates about next year
- [ ] Public thanks in wrap-up
- [ ] Future opportunities / advisory consideration

## Tutorial Crossover

Some keynote candidates also work as tutorial instructors.
When the invite order is decided, note which declined candidates might take a tutorial instead, and hand them to the tutorial recruiting track (see `cfp.md`).
