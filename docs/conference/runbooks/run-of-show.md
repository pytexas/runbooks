# Run of Show Runbook

Owned by Conference Chair (with Speaker and Venue committees).

A draft pitch-slot skeleton must exist before the prospectus ships (Month -7) so pitch slots can be written into sponsor contracts.
The final grid gets built about 2 weeks out.
Left alone it slips to 3-4 days out, and every retro complains; start earlier.

See `speaker-committee-runbook.md`, `day-of-operations-guide.md`.

## Purpose

Minute-by-minute schedule the team uses to execute the conference. Lives in a spreadsheet. Updated through the final week.

## Two Documents, Two Deadlines

1. Pitch-slot skeleton (Month -7, before the prospectus ships): which tiers pitch when, sponsored talk placement, workshop slots. This is what sales writes into contracts.
2. Final grid (~2 weeks out): every time slot, every lane, built from last year's sheet.

## Format

One sheet, one grid per day (Friday, Saturday, Sunday).

Columns: Time, Duration, Action, Registration/Hallway, Outside Work, Main Hall, Speaker, Notes.

The three role columns (Registration/Hallway, Outside Work, Main Hall) are parallel lanes so hallway staff, errand runners, and stage crew each see their own tasks at every time slot.

Recurring tasks embedded in the lanes:

- Check the green room before each talk block
- Check on sponsors twice daily
- Food setup and teardown around breaks
- Coffee pickup and urn return
- Catering arrival windows (breakfast 7:30-8:00, afternoon ~2:25-2:55)
- Store runs (Friday Costco + HEB trip during the morning tutorial)

## Sponsor Pitch Slots

- Pitches by tier: Platinum pre-keynote Saturday, Gold/Silver Sunday, Bronze during Saturday lightning talks
- A 20-minute sponsored talk sits immediately before lunch (Platinum benefit)
- Space pitches through the day; do not cluster
- Coordinate with Finance on ordering; a sponsor chaser rounds up presenters each morning
- Lock pitch slots before selling new sponsorships

## Sample Saturday

```
6:00  Venue access, setup begins
7:15  Coffee pickup
7:30  Food delivery
8:00  Registration opens, food out
8:55  Chair sets up opening; sponsor chaser rounds up presenters
9:00  Opening remarks (10)
9:10  Sponsor pitches, Platinum (2 min each, per the prospectus)
9:20  Keynote (~45)
10:05 Break + door prizes
10:20 Talk blocks: 25-min talk + 5-min Q&A/next-speaker setup
...   (breaks of 10-15 min interleaved)
12:05 Sponsored talk (20) + door prizes
12:30 Lunch: organizer-led group walks
2:00  Talks resume
2:25  Central Market afternoon delivery window
...
4:30  Sponsored workshop (90)
6:00  Lightning talks (30) + door prizes
6:35  Depart for network event
```

Sunday differs at the close: lightning talks ~4:45, closing remarks with door prizes ~5:25, out by 5:45.

## Door Prize Drawings

Spread through the day: after the keynote, before lunch, mid-afternoon, end of day.
Entry via Google Form.
Scattered drawings beat a single end-of-day block.

## Distribution

- Print copies for organizers, per day
- Digital link in the organizer chat
- A/V vendor gets a copy

## Final Updates

Week before:

- [ ] Confirm all speakers on slot
- [ ] Final sponsor pitch ordering
- [ ] Lunch announcements and restaurant map slide
- [ ] Door prize plan
- [ ] Sponsor thank-you slides ordered
- [ ] Prep last-day slides (announcements, recap) before day-of

Day before:

- [ ] Print run of show per organizer
- [ ] Brief team on changes

Each morning:

- [ ] Confirm changes from the previous evening
- [ ] MC has accurate intros and sponsor mentions
- [ ] Speaker timer set up per session

End of each day:

- [ ] Update the next day's grid based on adjustments
- [ ] Distribute the updated version

## Pitfalls

- Never let talks run early; it wrecks planned arrivals in person and online.
- Keep Python trivia or other filler ready for talks that run short.
- The pitch skeleton must exist before sponsorships are sold.
