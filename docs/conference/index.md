# Conference Documentation

Runbooks and role descriptions for the [PyTexas Conference](https://pytexas.org/conference).

## Roles

The conference is organized by six units, each with a lead, reporting in fixed order at every planning meeting:

* [Conference Chair](roles/conf-chair.md) (the Foundation President)
* [Speaker Chair](roles/speaker-chair.md)
* [Finance Chair](roles/fin-chair.md)
* [Marketing Chair](roles/mark-chair.md)
* [Venue Chair](roles/venue-chair.md)
* [Community Chair](roles/community-chair.md)

New to a role? Start with [Onboarding a New Committee Lead](runbooks/onboarding-new-lead.md).

## Runbooks

The [Conference Master Timeline](runbooks/conference-master-timeline.md) is the 12-month view across all committees.
Each committee has an end-to-end committee runbook plus topic runbooks for individual areas (CFP, sponsorship, venue, catering, swag, and so on), all listed in the site navigation.
