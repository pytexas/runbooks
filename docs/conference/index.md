# Conference Documentation

Runbooks and role descriptions for the [PyTexas Conference](https://pytexas.org/conference).
The conference is organized by six committees, each with a lead, reporting in fixed order at every planning meeting.
New to a role? Start with [Onboarding a New Committee Lead](runbooks/onboarding-new-lead.md).

The [Conference Master Timeline](runbooks/conference-master-timeline.md) is the 12-month view across all committees and the best place to start.
